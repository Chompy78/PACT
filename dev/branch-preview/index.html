🌿 PACT branch preview

loads any branch into its own worktree and serves it locally — never touches your real checkout
⚠ This is not a sandbox. Every branch you load here still points at the SAME live production Supabase project the real deployed app uses. If you sign in and use DM Console, CharGen, or Live Sheet through this preview, every action is real — awarding AP, editing a character, changing campaign rules, all of it hits the actual database, the same as if you'd done it on the real site. Loading a branch only changes which local FILES are served; it never creates a separate/test database.
How to use
  1. Pick a branch below and click Load — this checks it out into a separate worktree this tool owns (your own checkout of the repo is never touched, even if it's mid-task).
  2. Open one of the tool links under "Currently loaded" — each opens in a new tab, served from that branch's actual files.
  3. The branch list re-fetches from GitHub every time this page loads, so it stays current even if the underlying repo hasn't been fetched in a while.
  4. This tool doesn't run any install step — if a branch needs a new SQL migration applied or new dependencies, loading it here won't do that for you.
