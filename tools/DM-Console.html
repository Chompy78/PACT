    Gold & downtime economy
    Players Guide §16. Every purchase a character makes in play costs gold and downtime as well as AP, read off a single band; anything bought during character creation stays free of both. Pick one band at the start and hold to it — switching mid-campaign moves a purchase's price under the players' feet.

    🎬 Starting tier (new-PC budget)
    = AP · overridden
    Used for both ways into the campaign: it pre-fills the “Starting AP” field when you generate a player invite (still editable per invite), and it is granted automatically to a character that joins with the Players code above.     AP grant code ▸
    A grant code carries an amount and a note — nothing else. It is not tied to a character, so whoever pastes it into their Live Sheet receives that AP. (The old per-character tick list implied a binding that never existed, which is why the same code worked for anyone.) Share one code per player, or the same code with everyone if the award is the same.
